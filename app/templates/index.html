📡 Integration & Ingestion Quick Reference

1. Send Syslog over UDP (Port 514):
echo "<189>%LINK-3-UPDOWN: Interface GigabitEthernet0/1, changed state to down" | nc -u -w1 127.0.0.1 514
2. Send Syslog over TCP (Port 514):
echo 'date=2026-10-29 time=11:00:00 devname="FW-01" type="traffic" action="deny" srcip=10.0.0.5 dstip=8.8.8.8 msg="Denied"' | nc -w1 127.0.0.1 514
3. REST API - Query Device Logs:
curl -s
          "http://127.0.0.1:8321/api/v1/devices/10.0.0.1/logs?limit=50&severity=3&q=Gigabit"
4. Server-Sent Events (SSE) Stream:
curl -N
          "http://127.0.0.1:8321/api/v1/devices/10.0.0.1/stream"
